# 💬 Discussion Forum Assistant

AI that moderates online class discussions and provides helpful responses.

**Author:** Pranay M

## Features
| Module | Description |
|--------|-------------|
| Post Analyzer | Analyze discussion posts |
| Response Generator | Generate helpful responses |
| Topic Classifier | Classify discussion topics |
| Moderation Helper | Assist with moderation |
| Quality Assessor | Assess post quality |
| Engagement Tracker | Track engagement |
| Summary Creator | Create thread summaries |
| Thread Organizer | Organize discussions |
| Notification Writer | Write notifications |
| Analytics Reporter | Report analytics |
